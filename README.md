# Devil's Cute Horns AI

### Intelligent Academic Assistance. Designed for Android.

**Devil's Cute Horns AI (DCH AI)** is an AI-powered Android application designed to help users understand, process, and work with academic questions and documents.

Capture a question. Let AI analyse it. Review the response. Listen to the answer.

---

## Core Capabilities

- **Camera Capture:** Capture academic questions and documents using your phone.
- **AI Analysis:** Understand questions, instructions, requirements, and academic context.
- **Structured Answers:** Generate organised responses while respecting question choices, answer limits, and instructions.
- **Voice Playback:** Listen to generated answers using Android text-to-speech.
- **Study Sessions:** Maintain locally stored study sessions and captured content.
- **Background Processing:** Designed to maintain processing sessions when the screen is locked and recover from connectivity interruptions.

## How It Works

1. Capture an academic question or document.
2. Submit the content for AI processing.
3. AI analyses the material and generates a response.
4. Review the answer or listen through voice playback.

## AI API and Token Usage

DCH AI connects to an external AI provider through an API.

AI processing consumes tokens, which measure the amount of text processed by an AI model.

- Internet access is required for cloud-based AI processing.
- API usage may incur charges depending on the provider and model.
- Token consumption depends on input size and generated responses.
- API credentials must remain private and must never be committed to the repository.

Voice playback uses Android text-to-speech functionality.

## Privacy and Storage

The initial release uses local device storage for application data and study sessions.

Cloud synchronisation and hosted storage are reserved for future development.

Users should exercise care when submitting confidential documents to external AI providers.
