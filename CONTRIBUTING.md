# Contributing to Devil's Cute Horns AI

Thank you for your interest in contributing to Devil's Cute Horns AI (DCH AI).

We welcome developers, testers, designers, and technical contributors who want to improve the project.

## Ways to Contribute

You can contribute through:

- Bug reports and troubleshooting.
- New feature proposals.
- AI API integration improvements.
- Token usage optimisation.
- Android compatibility improvements.
- Interface and accessibility enhancements.
- Performance and reliability improvements.
- Documentation and testing.

## Getting Started

1. Visit the official repository:
   https://github.com/Fulltech-Inc-Networks/DevilsCuteHornsAI
2. Fork the repository.
3. Clone your fork.
4. Create a separate branch for your contribution.
5. Make and test your changes.
6. Push your branch to your fork.
7. Open a Pull Request against the original repository's main branch.

## Branch Naming

Use descriptive branch names.

Examples:

- fix/camera-capture
- feature/voice-controls
- improve/api-efficiency
- docs/update-readme

## Contribution Standards

Please ensure your contributions:

- Address a clearly identified problem or introduce a useful improvement.
- Preserve existing application functionality.
- Follow existing architecture and coding conventions.
- Avoid unnecessary changes to unrelated files.
- Include appropriate testing where possible.
- Explain the purpose of your changes.

## Security Requirements

Never commit or publish:

- Private AI API keys.
- API provider secrets.
- Android signing keystores.
- Signing passwords.
- Private credentials or access tokens.
- Personal user data.

Never expose sensitive information through application logs.

Report security vulnerabilities privately to the repository maintainer instead of publishing exploitable details in public issues.

## Pull Request Guidelines

Every Pull Request should explain:

1. What was changed?
2. Why was the change necessary?
3. How was it tested?
4. Are there known limitations?

Keep contributions focused and easy to review.

All Pull Requests are subject to maintainer review. Submission does not guarantee acceptance.

## Issues and Feature Requests

Before opening a new issue, check whether a similar report already exists.

For bug reports, include:

- Device and Android version.
- Application version.
- Steps to reproduce.
- Expected behaviour.
- Actual behaviour.
- Relevant logs or screenshots, with private information removed.

## Project Governance

The original repository is maintained by the project owner.

Contributors retain authorship of their original contributions, subject to applicable licensing terms.

Contributions may be reviewed, modified, accepted, or declined by the maintainer.

Direct repository write access is granted at the maintainer's discretion.

Every meaningful contribution helps improve Devil's Cute Horns AI.

Whether you report a bug, suggest an improvement, write documentation, or submit code, your participation is welcome.
