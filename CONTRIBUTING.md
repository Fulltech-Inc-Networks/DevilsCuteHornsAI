# Contributing to DCH AI

Devil's Cute Horns AI welcomes developers interested in improving the application's functionality, performance, security, and overall quality.

## Areas of Contribution

- Android development and architecture.
- AI integration and prompt engineering.
- API efficiency and token optimisation.
- Camera and document processing.
- Voice playback and accessibility.
- Performance and reliability.
- UI/UX improvements.
- Testing and documentation.

## Contribution Process

1. Fork the repository.
2. Create a branch for your changes.
3. Implement and test your contribution.
4. Submit a Pull Request to the official `main` branch.
5. Provide a clear description of your changes.

## Development Standards

- Maintain compatibility with existing functionality.
- Follow established project architecture and coding conventions.
- Avoid unnecessary dependencies and unrelated modifications.
- Test changes before submitting them.
- Document significant implementation changes.

## Security

Never commit API keys, private credentials, signing keystores, passwords, or sensitive user data.

Security vulnerabilities should be reported privately to the maintainer.

## Review and Acceptance

All contributions are subject to maintainer review. Pull Requests may be approved, revised, or declined.

Official releases and repository administration remain under the authority of the project maintainer.
